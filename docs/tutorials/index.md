# Tutorials

Learning-oriented lessons that take you from nothing to a working result. The four tutorials tell one continuous story: a digital twin of a real cell, the Molicel INR21700-P45B, built from its live BattINFO registry record, bound to an openly licensed equivalent-circuit model, simulated in PyBaMM, linked to the lab measurements behind that model, calibrated to the physical cell with PyBOP, and versioned with a verifiable hash chain at every step. Every command's real output is shown along the way.
